PS5 Linux — Ali Edition v5

المصدر:
- مبني على ps5-linux-loader-main.zip الأصلي الذي رفعه المستخدم.
- مصدر C الأصلي ومجلدات include وshellcode وoffsets بقيت كما هي دون تعديل.

الإضافات:
- plymouth/background.png: خلفية مخصصة باسم ALI / علي.
- plymouth/ps5-linux-ali.plymouth وplymouth/ps5-linux-ali.script: ثيم Plymouth مع callback للتقدم والرسائل.
- plymouth/install.sh: تثبيت تفاعلي مع نسخة احتياطية وتحديث initramfs داخل Linux المستهدف.
- plymouth/rollback.sh: تراجع عن الثيم داخل Linux المستهدف.
- BUILD_GUIDE_AR.md: تعليمات البناء والتثبيت والتراجع بالعربية.
- build-check.sh: فحص وجود SDK وبناء ELF والتحقق من وجود الناتج.

لا توجد تغييرات على payload أو kernel exploit أو hypervisor code أو offsets.
لم يتم إجراء build باستخدام Prospero SDK في بيئة إنشاء الملف؛ يجب التحقق من البناء داخل WSL الخاص بالمستخدم.
